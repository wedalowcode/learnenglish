# 微搭前端自定义方法 Skill

## 文件

| 文件 | 说明 |
|------|------|
| `SKILL.md` | Skill 正文（加载到 AI）— 自定义方法骨架、数据源 CRUD 速查、关联字段、$w.utils |
| `references/api-frontend.md` | 完整前端 API 参考：$w.utils、callDataSource 全套 CRUD、Filter 运算符、关联读写、实战示例 |
| `README.md` | 本说明 |

## 安装

1. 目录名必须为 `weda-custom-method`
2. 放入 `SKILL.md`
3. 可选保留 `references/api-frontend.md`（推荐保留，写代码时查参数）
4. 拷贝到 Cursor / Trae / 其他 Agent Skills 目录

## 触发说法示例

- 「写一个微搭自定义方法，按钮点击提交表单」
- 「帮我写 callDataSource 查多条数据」
- 「主表加明细的提交逻辑怎么写」
- 「关联字段怎么读写」

## 配套技能

| 技能 | 管什么 |
|------|--------|
| **本技能** | 自定义方法骨架、数据源 CRUD、$w.utils |
| `weda-component-api` | 查 `$w.listView1.refresh()` 等组件实例方法 |
| `weda-component-jsx` | 写自定义 JSX 组件 |
| `weda-cloud-function` | 写云函数 |
