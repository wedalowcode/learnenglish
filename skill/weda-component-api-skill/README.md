# 微搭内置组件 API 速查 Skill

## 文件

| 文件 | 说明 |
|------|------|
| `SKILL.md` | Skill 正文（加载到 AI）— 组件索引、调用约定、最常用方法速查 |
| `references/components.md` | 20 个内置组件完整 API：方法表、属性表、事件出参、推荐用法、注意点 |
| `README.md` | 本说明 |

## 安装

1. 目录名必须为 `weda-component-api`
2. 放入 `SKILL.md`
3. 可选保留 `references/components.md`（推荐保留，查组件方法时用）
4. 拷贝到 Cursor / Trae / 其他 Agent Skills 目录

## 触发说法示例

- 「listView 怎么刷新」
- 「$w.form1.setValue 参数怎么传」
- 「WdTable 怎么清空选中行」
- 「弹窗组件 open 方法怎么用」
- 「树组件怎么获取选中节点」

## 配套技能

| 技能 | 管什么 |
|------|--------|
| `weda-custom-method` | 自定义方法骨架（try/catch、callDataSource、$w.utils） |
| **本技能** | 内置组件实例方法与属性速查 |
| `weda-component-jsx` | 自定义 JSX 组件 |
| `weda-cloud-function` | 云函数 |
