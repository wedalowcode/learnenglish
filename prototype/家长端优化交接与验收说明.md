## 二、信息架构（页面流程）

```
首页 home.html
  ├─ 消息与待办（置顶）：待复习 / 新报告 / 课时预警 / 套餐临期 / 教务回复 → 动作按钮；无待办正向反馈
  │     └─ 全部消息 › notifications.html（统一消息中心，一键已读）
  ├─ 课时 hero：剩余 +「按每周 X 节约可支撑 Y 周」
  ├─ 孩子信息 / 学习概况（含家庭复习勾选进度）
  ├─ 最近反馈：表现亮点 / 需要加强 / 家庭建议（新报告红点）
  └─ 报名订单
报告 report.html
  ├─ 列表：日期筛选 + 仅看未读（新标/已读降权）
  └─ 详情：一句话总结置顶 → 概况 → 单词学习(掌握率进度条+待加强跳转) → 文章 → 教师反馈
          → 家庭配合建议(可勾选) → 趋势(含解读) → 底部行动区(待复习/打印/联系)
单词表 review-words.html
  ├─ 手机复习模式：大卡逐词 + 听音 + 遮盖/显示中文 + 家庭已复习勾选 + 进度 X/Y
  ├─ 打印清单（A4）+ 导出 PDF（打印另存）
  └─ 仅显示未勾选 / 筛选 / 空状态引导
课时 hours.html
  ├─ 课时 hero（周数估算）/ 提醒（联系续费、看套餐）
  ├─ 课时账户（多套餐）
  ├─ 最近扣课记录（只读）
  ├─ 推荐套餐（仅展示）+ 订单历史（白话状态）
  └─ 联系教务 + 我的咨询（新高亮/已回复）
课程记录 course-records.html
  └─ 课程详情抽屉：含报告摘要(训练单词数+一句话)；未上/已取消 → 联系教务
```

## 三、数据模型变化（附加式，无破坏性迁移）

1. 新增 `db.parentReportReads`：`{ id, parentId, studentId, reportId, readAt }` —— 家长报告已读辅助记录。
2. 新增 `db.parentAdviceChecks`：`{ id, parentId, studentId, reportId, itemKey, checked, at }` —— 家庭建议勾选辅助记录。
3. `normalizeDb` 为两者补空数组与 `seq.PRR/PAC`；旧数据加载自动补齐，不改动既有集合。
4. **不修改** `reports/report.content`、`studentWordStates`、莱特纳/21 天：家庭勾选/建议勾选/已读仅为家长辅助记录，不改变正式教学状态（测试已断言）。

## 四、新增 / 修改的 Store 接口

| 接口 | 类型 | 说明 |
|---|---|---|
| `parentLessonFlows(parentId, studentId)` | 新增 | 近 10 条扣课记录（`at/topic/delta/after/courseId`），只读 |
| `parentReports(parentId, studentId, {unread?})` | 修改 | 增加 `read` 标记；`unread:true` 仅返回未读 |
| `parentReportDetail(...)` | 修改 | 增加 `read` 标记 |
| `parentReportReads` / `markParentReportRead` | 新增 | 已读集合读取 / 标记已读（校验归属与已发布） |
| `parentAdviceChecks` / `toggleParentAdviceCheck` | 新增 | 家庭建议勾选读取 / 切换（不改报告与学习状态） |
| `parentReviewProgress(parentId, studentId)` | 新增 | 今日到期复习的 `{due, checked, remaining}` |
| `parentHours(parentId)` | 修改 | 每学员增加 `weeklyEstimate`、`weeksEstimate`（剩余÷每周） |

全部接口走 `assertParentChild`（家长身份 + 学员归属校验），不信任前端传入。

## 六、未验证 / 部分实现 / 已知问题

1. **页面交互未浏览器实跑**（🔧）：通知折叠、TTS 播放、勾选即时反馈等建议上线前做一轮真机验收。
2. **多孩子切换样式统一为「功能性一致」**（⚠️ 部分）：各页均通过 `setParentCurrentChild`/URL 同步当前孩子；但 review-words 工具栏使用下拉选择，其余页使用分段 seg，形态未完全统一。
3. **待加强单词「一键高亮」**（⚠️ 部分）：报告详情页跳转到单词表 `view=all`，因报告投影未暴露具体薄弱词 ID，暂未按单词精准高亮。
4. **导出 PDF**（⚠️）：通过浏览器打印「另存为 PDF」实现（并自动隐藏工具栏），非后端生成 PDF。
5. **统一消息中心**（⚠️ 部分）：入口为首页「消息与待办」卡 + 根目录 `notifications.html`；`notifications.html` 为桌面布局（`Proto.shell`），家长移动端体验未专门优化。
6. **第三批未做**（⚠️）：学习成长小结（本月数据）、报告分享图片、更细的新手引导未实现。
