教师是资源池，不是员工记录。「合作状态」表达这个人跟机构的关系（待启用 / 可授课 / 暂停合作 / 已退出）， 「账号状态」只表达登录凭证能不能用，两者互不推导；「本月课程 / 本月课时 / 最近授课 / 当前学员」全部由课程表与师生关系实时计算，不存静态数字 （本月课程与本月课时按本月已完成课程统计，待上课与已取消不计入）。
