## 二、信息架构（页面流程）

```
今日工作台 workbench
  ├─ 统计卡（待写报告可点直达）
  ├─ 今日课程：一键进入课堂 / 继续课堂；报告快捷 写报告 / 发布
  ├─ 待写报告：带入本节数据填写 / 发布给家长
  └─ 需要关注的学员（今日到期 / 通过率偏低 → 学员档案）
        ↓
课程工作台 course-workbench?course=
  ├─ 顶部：继续上次训练（大按钮）/ 今日到期：莱特纳X·21天Y / 可关闭建议路径
  ├─ 四个教学入口（单词/莱特纳/21天/文章）
  ├─ 教师备注：文本 + 学员状态/需教务配合
  └─ 完成课程：结果预览（扣1课时·生成报告草稿·家长暂不可见）+ 剩余默认保留
        ↓
单词训练 setup → prescreen（←/→）→ word-training（1-5/空格, 最后复习 1/2/3）→ 结果页关键变化
        ↓
学员档案 student-profile：本节课建议（到期/通过率/薄弱词）+ 一键去训练 + 仅看今日到期/待加强
        ↓
教学报告 course-report：四类模板 + 家庭建议 + 家长预览 + 发布；教学记录：处理下一份
```

## 三、数据模型变化（附加式，无破坏性迁移）

1. 课程教学记录（`courseRecords`）追加可选结构化字段：`teachState`（专注/一般/疲惫）、`needStaff`（是/否），经 `saveNote` / `doFinish` 写入，旧记录缺省为空。
2. 报告内容沿用既有 `content.performance/weak/next/homeworkAdvice`；本次仅在报告表单中新增「家庭配合建议」输入并带入 `homeworkAdvice`（`saveReportDraft` 已支持）。
3. 无新增集合、无字段删除；历史课程/报告/训练数据不受影响。

## 四、新增的 Store 接口（均已导出）

| 接口 | 说明 |
|---|---|
| `teacherTodayOverview(teacherId, date)` | 今日课程（含学员/报告状态/会议链接）+ 统计 + 待写报告 + 需要关注学员 |
| `teacherDueReviewSummary(studentId)` | 今日到期复习合并：`{leitner, plan21, total, leitnerDetail, plan21Detail}`（仅展示，执行仍分体系） |
| `teacherAttentionStudents(teacherId)` | 需要关注学员：今日有到期复习 或 最近一次通过率<50% |
| `teacherLessonAdvice(studentId)` | 本节课建议：`{dueReview, weakWords[], lastPassRate, lastTaskId}` |
| `courseRecordAutoData(courseId)` | 报告自动带数：训练单词/掌握/待加强/莱特纳/21天/文章句（对齐课程记录快照） |

归属校验：教师角色经 `assertSelfTeacher / assertMyStudent`；课程经 `_assertMyCourse`（课程 teacherId 必须为当前教师）。不信任 URL 参数。
