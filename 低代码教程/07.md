# 前言
上一节已经完成了基础单词表和词库单词关联表的创建，并初步建立了词库与单词之间的关系。

但是，目前我们还缺少一个实际管理这些关联数据的页面。

例如，我们创建了一个“人教版三年级上册”词库，接下来需要能够查看这个词库包含哪些单词，也需要能够从基础单词表中选择单词添加到当前词库。

本篇实现词库单词管理功能，主要包括：

1. 创建词库单词管理页面。
2. 通过 URL 参数接收当前词库 ID。
3. 使用数据表格展示当前词库已经关联的单词。
4. 在操作列增加移除功能，从当前词库中移除单词。

本篇只操作词库单词关联表，不删除基础单词表中的原始单词。

## 2. 添加 URL 参数

这个页面需要知道当前正在管理哪一个词库。

例如，从词库列表点击“管理单词”时，需要把当前词库的 ID 传递到这个页面。

选中页面节点，在页面属性中找到 URL 参数配置，添加一个参数：

| 配置项 | 值 |
|---|---|
| 参数名称 | wordbookId |
| 参数类型 | 文本 |

![在这里插入图片描述](https://i-blog.csdnimg.cn/direct/f1e164fca6bc4a21847340e02cf5a650.png)
![在这里插入图片描述](https://i-blog.csdnimg.cn/direct/063680bd92574ca1a7b61ea6d5fff900.png)


这里的 `wordbookId` 就是当前词库在 `biz_wordbook` 表中的数据标识。

后续进入页面时，URL 中会携带这个参数。

例如：

```text
词库单词管理?wordbookId=当前词库ID
```

具体 URL 形式以微搭实际生成的页面地址为准。

## 3. 读取 URL 参数

页面自定义方法和组件可以通过页面参数获取当前词库 ID。

在后续自定义方法中，使用：

```javascript
const wordbookId = $w.page.dataset.params?.wordbookId;
```

这样，无论进入的是人教版三年级上册，还是其他教材词库，页面都能根据传入的 ID 展示对应的单词。

注意：不能在页面中写死某一个词库 ID，否则页面就只能管理一套教材。

## 2. 编写移除方法

在代码编辑器中贴入如下代码：

```javascript
export default async function ({ event, data }) {
  try {
    // 1. 获取当前关联记录ID
    const relationId =
      data?._id ||
      data?.record?._id ||
      event?.detail?.record?._id;

    if (!relationId) {
      $w.utils.showToast({
        title: '缺少数据标识',
        icon: 'error',
        duration: 2000,
      });
      return;
    }

    // 2. 删除词库单词关联记录
    const result = await $w.cloud.callDataSource({
      dataSourceName: 'biz_wordbook_word',
      methodName: 'wedaDeleteV2',
      params: {
        filter: {
          where: {
            _id: {
              $eq: relationId,
            },
          },
        },
      },
    });

    // 3. 判断删除结果
    if (!result || result.count === 0) {
      $w.utils.showToast({
        title: '移除失败',
        icon: 'error',
        duration: 2000,
      });
      return;
    }

    // 4. 成功提示
    $w.utils.showToast({
      title: '移除成功',
      icon: 'success',
      duration: 2000,
    });

    // 5. 刷新当前表格
    $w.tableWordbookWord.refreshKeepPage();

  } catch (error) {
    console.error('移除词库单词失败:', error);

    $w.utils.showToast({
      title: error?.message || '移除失败',
      icon: 'error',
      duration: 2000,
    });
  }
}
```

注意：

- `biz_wordbook_word` 是词库单词关联表的模型标识。
- `relationId` 是关联表记录的 `_id`。
- `wedaDeleteV2` 是删除单条记录的方法。
- `$w.tableWordbookWord` 是当前页面数据表格的组件 ID。

如果你的数据表格实际组件 ID 不是 `tableWordbookWord`，需要替换为编辑器中真实的组件 ID。

另外，在配置按钮事件时，要确认传递给方法的 `data` 确实是当前操作行记录。如果事件配置传递的是其他结构，可以先通过 `console.log(event, data)` 检查实际参数，再调整取值方式。

# 总结

本篇完成了词库单词管理功能。

通过一个页面，实现了当前词库单词的查询、移除。

本篇涉及的核心技术有：

- URL 参数：接收当前词库 ID。
- 数据表格：展示词库关联数据和基础单词数据。
- 数据筛选：根据词库 ID 限定当前表格的数据范围。
- 表格选中 API：获取用户勾选的基础单词。
- 自定义 JavaScript 方法：实现移除业务逻辑。
- 数据模型 CRUD：调用删除 API。

至此，我们已经可以通过管理应用维护一本教材所包含的单词。

后续再结合 WorkBuddy 自动化初始化教材词库，就能够先建立基础单词，再批量建立词库与单词之间的关系，而不需要人工逐条操作。
