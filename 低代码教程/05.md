# 一、前言

上一篇我们完成了代理管理功能，建立了代理的基础数据模型，并通过微搭模板生成了代理列表和表单页面。

本篇开始开发英语教学平台的词汇管理模块。

在英语教学业务中，不同教材、年级、学期和教学单元都有各自的词汇范围。例如：

- 人教版三年级上册 Unit 1
- 人教版三年级上册 Unit 2
- 外研版四年级上册 Module 1
- 小学英语课外拓展词汇

这些词汇需要按照不同的教学场景进行组织。因此，我们首先需要建立一个词库管理功能。

这里需要区分三个概念：

1. **词库**：用于组织和管理一组单词，例如人教版三年级上册 Unit 1。
2. **单词**：具体的英文单词，例如 apple、book、school。
3. **词库与单词的关系**：一个词库包含多个单词，同一个单词也可能被多个词库使用。

本篇先完成词库管理，只维护词库的基本信息。后续再创建基础单词表和词库单词关联表。

## 2.2 添加词库字段

词库表主要保存词库的基本信息。

按照下面的结构添加字段：

| 字段标识 | 字段名称 | 字段类型 | 说明 |
|---|---|---|---|
| _id | 系统主键 | 系统字段 | 微搭自动生成 |
| name | 词库名称 | 文本 | 词库名称，设置为主列字段 |
| category | 词库分类 | 枚举 | 教材词库、拓展词库等 |
| book_version | 教材版本 | 文本 | 人教版、外研版等 |
| school_stage | 学段 | 枚举 | 小学、初中、高中 |
| grade | 年级 | 文本 | 三年级、四年级等 |
| term | 学期 | 枚举 | 上册、下册 |
| unit | 单元 | 文本 | Unit 1、Unit 2 等 |
| description | 词库说明 | 多行文本 | 词库用途说明 |
| status | 状态 | 枚举 | 启用、停用 |

其中，`_id` 是系统主键，由微搭自动维护，不需要手动创建。
![在这里插入图片描述](https://i-blog.csdnimg.cn/direct/cfb80abd4d9240fc8637eeb9908408e0.png)

## 2.3 配置枚举字段

词库分类 `category` 可以设置以下选项：

- 教材词库
- 拓展词库
- 自定义词库

学段 `school_stage` 设置：

- 小学
- 初中
- 高中

学期 `term` 设置：

- 上册
- 下册

状态 `status` 设置：

- 启用
- 停用

这里需要注意，词库分类、学段和学期是不同维度的信息。

例如，一个词库可以同时属于教材词库、小学、上册。不要把这些信息全部合并成一个分类字段。

## 2.4 设置主列字段

在数据模型中，将 `name` 词库名称设置为主列字段。

主列字段是微搭在关联选择、数据展示等场景中使用的主要显示字段。

后续创建词库单词关联表时，需要通过词库名称识别所属词库，因此这里使用 `name` 作为主列字段。

![在这里插入图片描述](https://i-blog.csdnimg.cn/direct/d602057c855044d6a62417a8d6839973.png)


完成字段配置后，保存数据模型。

# 本篇总结

本篇完成了英语教学平台的词库管理基础功能。

我们创建了 `biz_wordbook` 词库数据模型，并通过微搭模板生成了词库列表、新增、编辑和查看页面，最后将词库管理添加到了教务工作区的导航菜单中。

到目前为止，平台已经具备了教师、代理和词库三类基础数据的管理能力。

接下来需要解决一个更重要的问题：

**词库中的单词应该如何保存？**

这里不能简单地把单词直接作为词库表中的一个字段，也不建议每个词库都重复保存一份单词数据。

例如，apple 可能同时出现在人教版三年级上册、课外拓展词库和其他教材中。如果每个词库都单独保存一份 apple，后续维护音标、释义和发音时就会产生大量重复数据。

因此，下一篇我们将创建独立的基础单词表，并设计词库与单词之间的关联关系，为后续 Excel 批量导入和单词训练功能打好数据基础。
